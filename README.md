# Lab Report Explainer 🩺

Blood test report PDF upload pannina, ovvoru value-um LOW / HIGH / NORMAL nu check panni, **Tamil-la** simple-a explain pannum web app.

## 🔗 Live Demo
[Inga click panni app-a try pannunga](https://lab-report-explainer-cgxdtecjiu2jxozgwzhedr.streamlit.app/)

## Features
- Digital PDF-la irundhu test values extract
- Normal range-oda compare panni LOW / HIGH / NORMAL status
- Tamil explanation (possible reasons, risk factors, diet tips, doctor-a eppo paarkanum)
- Disclaimer and emergency warning

## Tech Stack
Python, pdfplumber, Pandas, Streamlit

## Limitations
- Digital PDF mattum (scanned photo support innum illa)
- 11 common tests mattum (CBC, sugar, cholesterol, TSH)

## Future Plans
- Photo / scanned report support (OCR)
- More tests (Vitamin D, Creatinine, Liver)
- AI-powered explanation for any test

## Disclaimer
Idhu education-ku mattum. Medical advice illa. Doctor-a paarunga.
